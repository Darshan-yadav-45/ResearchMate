IBM Cloud Lite Setup Guide

Step 1: Sign up for IBM Cloud Lite

Create a free IBM Cloud Lite account at cloud.ibm.com/registration (no credit card required).

Step 2: Create a watsonx.ai Project

Log into dataplatform.cloud.ibm.com, create a new Project, and copy your Project ID from Manage > General > Details.

Step 3: Generate an IAM API Key

Go to cloud.ibm.com/iam/apikeys, click Create an IBM Cloud API key, and copy your key.

Security Guarantee

Keys are saved exclusively in your local .env file. ResearchMate never transmits your keys to third parties.
