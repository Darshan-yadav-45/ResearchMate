REST API Quick Start

Pass your JWT token in the Authorization HTTP header using the Bearer <token> scheme:

cURL (Verify Profile) 
curl -X GET http://127.0.0.1:5000/api/auth/profile \
  -H "Authorization: Bearer <YOUR_JWT_TOKEN>"
Python (requests) 
import requests

token = "{{ jwt_token[:30] }}..."
headers = {"Authorization": f"Bearer {token}"}

response = requests.get("http://127.0.0.1:5000/api/auth/profile", headers=headers)
print(response.json())
API Token Endpoint 
curl -X POST http://127.0.0.1:5000/api/auth/token \
  -H "Content-Type: application/json" \
  -d '{"username": "{{ current_user.username }}", "password": "<your_password>"}'
